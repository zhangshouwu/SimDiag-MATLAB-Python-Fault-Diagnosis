# Upwork Portfolio Draft

**Title:** MATLAB/Simulink + Python Desktop Tool for Actuator Fault Simulation & Analysis

**Role:** Python and MATLAB/Simulink integration, simulation workflow and analysis GUI

**Description:**
Developed a bilingual desktop prototype that integrates Python with MATLAB/Simulink to automate closed-loop actuator loss-of-effectiveness (LOE) simulation studies. The tool compares healthy and fault-injected responses, calculates residual-based diagnostics, performs offline robustness benchmarks under diagnostic-channel noise and plant-model mismatch, and generates charts and structured reports. It also demonstrates causal recursive least-squares (RLS) estimation on logged data in offline replay.

**Deliverables:** Python/Tkinter desktop GUI, Simulink demo model, configurable experiment runner, response/residual/estimation plots, JSON metrics and bilingual text report.

**Technologies:** MATLAB, Simulink, MATLAB Engine for Python, Python, NumPy, SciPy, Matplotlib, Tkinter.

**Scope:** Simulation prototype; not validated on physical hardware and not a production real-time fault detector.
